# Recipe Organizer

Recipe Organizer is a lightweight Python application for managing a personal recipe collection.

## Features

- Create recipes
- Categories
- Ingredient search
- Favorites
- Statistics
- JSON storage
- Markdown export

## Requirements

- Python 3.11+

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Project Structure

- src/
- tests/
- docs/
- data/
